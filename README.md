# java-calculator-precourse

# 요구사항 :

### 1. 쉼표, 콜론 구분자로 구분된 숫자 -> 구분자 기준 분리

### 2. 커스텀 구분자 지정 가능.

가장 앞부분 "//", "\n"를 두고, 그 사이에 넣은 문자를 구분자로 지정.
ex) "//;\n1;4,5" -> ";"를 구분자로 지정.

### 3. 잘못된 값 입력시 `IllegalArgumentException` 발생시키고 애플리케이션 종료.

# 기능 구현

1. 커스텀 구분자 판단 & 구분자 생성
2. 일반 구분자로 생성 - 이것도 없으면 예외처리
3. stream() 이용해서 list 생성.
4. 음수 판단
5. return sum
